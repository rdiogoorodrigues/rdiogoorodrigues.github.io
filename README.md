# Rui Diogo Rodrigues — CV website

Static one-page CV (`index.html` + `assets/photo.jpg`), aimed at health-tech companies and healthcare consulting.

- Preview locally: open `index.html` in a browser.
- Publish: enable GitHub Pages (Settings → Pages → branch, root).
- Replace the photo: overwrite `assets/photo.jpg` (portrait, 4:5, at least 800×1000 px).
